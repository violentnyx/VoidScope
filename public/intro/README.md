# Arquivos da intro

- `logo.mp4` — logo em repouso, convertido para H.264;
- `power-on.mp3` — motor de inicialização com fade antes da logo.
- `logo-appear.mp3` — som sincronizado à formação da logo.
- `glitched.mp4` — transição de glitch, convertida para H.264.
- `vhs-glitch.mp3` — efeito VHS sincronizado aos dois segundos de glitch.
- `shader-entry.mp3` — ambiente que acompanha a entrada do shader e conteúdo.

Os originais em HEVC permanecem fora do projeto. As versões daqui foram
reduzidas e preparadas para reprodução ampla nos navegadores.

O fluxo e seus tempos ficam em `src/components/intro/intro-config.ts`.
Os efeitos sonoros ainda serão adicionados separadamente.
